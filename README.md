# Calculadora Python

## Descrição

Este projeto contém um programa simples em Python e um script Shell para executá-lo.

## Arquivos

* calculadora.py
* calculadora.sh
* comandos.txt

## Como executar

Primeiro conceda permissão de execução ao script:

```bash
chmod +x calculadora.sh
```

Depois execute:

```bash
./calculadora.sh
```

## Explicação do código Python

O arquivo `calculadora.py` contém um programa simples que exibe a mensagem:

"Calculadora funcionando"

O objetivo é demonstrar a execução de um script Python através de um arquivo Shell.
